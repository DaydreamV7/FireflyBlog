游玩时长：2.5h

大本营等级7

从夯到拉：人上人

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">整体初印象与总评</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">关键词：休闲养成、繁忙点点、挂机培养</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">总体评价：挂机休闲点点点最后衍生PVP的游戏</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">加分项：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">轻松。你一开始玩不需要什么脑子，搭配阵容一键加点什么的，库库点就好了</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">新手保护期。像这种强烈社交熟悉的挂机养成游戏，有新手期至少不会被别的高玩一开始打死。</font>
3. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">强社交。这种游戏的最终核心游戏性不是养成，而是攻占，更不是攻占NPC，什么“演练”、“开垦”而是结盟地PVP。另一种性质认知的《传奇》类游戏？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">减分项：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">游戏机制。实际上整场游戏体验你换感觉不是你体验游戏的乐趣，而是游戏或者说背后的设计在筛选你。你必然是那个有着空闲时间点点点点，不断繁忙小策略把当天的资源利用干净。这需要满足挂机休闲，最后养成好的势力去攻打别人的玩家群体。实际上是弱乐趣，纯粹消磨时间的游戏产品。实际上这种游戏产品比如桌宠什么的存在是有意义的。但从游戏性的表现，不是很好玩。桌宠的覆盖面很广而这类游戏太挑玩家了。</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">游戏策略。虽然有克制关系什么的。但我没有排兵布阵的感受，还有其他的想法。你直接玩《骑马与砍杀》打个什么MOD，也能玩上帝视角攻占其他领地的玩法。没有游戏性乐趣还有思考我玩什么？</font>
3. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">强社交。你肯定不能一个人玩自己的。肯定能被莫名其妙烧了大本营，在《剑灵》就会被敌对阵营围杀在新手村。</font>

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心玩法体验</font>
+ <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">这款游戏最核心的玩法有没有抓住你？它给你带来的核心爽点、最让你难受 / 无聊的点分别是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  作为开放世界它很好的承接了探索和收集这两要素对于《幻兽帕鲁》的对标来看待。  
</font><font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  核心爽点：</font>

1. 消磨时间的点点点。
2. 不断培养壮大自己的势力

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  难受点：</font>

1. 没有显著的游戏性体现
2. 繁琐。你很可能大部分时间打磨在上面的资源培养上，时间用完后挂机等回复。不能一直玩，不能一直进行决策。

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">长线游玩体验</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">随着游玩时长增加，你对这款游戏的兴趣是上升、持平还是快速下降？你觉得影响你持续玩下去 / 想要弃坑的核心原因是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">快速下降。本身这种游戏受众较少。游戏性拉跨。</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心原因：游戏机制。</font>
