# 游戏体验
（我记得知乎有杀戮尖塔的拆解案[https://zhuanlan.zhihu.com/p/650859964](https://zhuanlan.zhihu.com/p/650859964)，以我的拙见肯定写得没它好）

  游戏战斗卡牌组成主要围绕四个维度来

+ 运转：每个回合固定抽5张牌
+ 费用：每个回合基础有3个能量
+ 格挡：挡住敌人的进攻
+ 攻击：削减敌人HP达到胜利的条件

  其他的Buff暂时不提及。《杀戮尖塔2》延续着1代的设计，这其实和《消逝的光芒：困兽》没什么区别，偏贬义一点是炒冷饭，褒义一点就是新的游戏内容。《杀戮尖塔2》引入了储君和死灵法师，我没有深刻地去体验两种角色单从铁甲战士来讲。我觉得炒冷饭多一点，因为一个游戏的变化是要和机制变化的。而为什么《刺客信条2》系列我会认为不是炒冷饭？因为我的滤镜太好了，《刺客信条2》的战斗机制在《刺客信条：兄弟会》增加了枪，弩，刺客行动等，即使引入了其他武器系统来丰富战斗方式，但实际上作为角色扮演游戏这游戏战斗机制是为了贴近角色扮演，很容易穷尽，但吸引玩家持续玩下去的心流和体验是剧情占更多。所以你扮演刺客大师Ezio是不会感到突兀和不爽的。

  杀戮尖塔刚开始玩是很开心的，体验不同的游戏内容，进行不同的游戏决策，是很好玩的。当随着越后面越难。那么你再怎么搭配你的卡牌，都需要关键牌。比如你缺运转，来的都是什么铁斩波，闪电霹雳，结果一张祭品，战斗专注都没来导致你启动慢被敌人三回合斩于马下，不好玩。此时你就知道，游戏最优解有穷尽。

## 铁甲战士体验
  一开始游玩是很令人兴奋的，因为是新的游戏内容，这就像《CS2》里面的Falcon战队一样，保持变阵更令人充满想象。

  铁甲战士直观一点流派有：易伤流，易伤力量流，格挡翻倍，剑柄打击循环，易伤循环等。我提到的是我现在迅速想起的，也有其他的比如未知宝石。

  那么从怪物的体验来看就有三个维度，运转（启动）、增费、伤害。而且现在的卡牌易伤多点，已经没有的重振精神、硬撑和巩固的起盾肚皮流，也没有翻倍力量流。我没有玩猎手，至少我觉得当前测试版本品味过久实在是太失望了。因为卡牌的规定，怪物的固定，最优解的有限使得游戏乐趣实际上越后面越容易磨损。  
  只不过Rouge特点的随机化大大的延长了游戏寿命和掩盖了它最优解游戏策略的形成。当玩家知道应该组成什么牌之后，随机不到那就不能成型，不能成型最优解很难打不到最终Boss。

  而且当前的小怪，精英怪，Boss环境特别吃运转，增费，群伤。

[卡牌游戏最易让玩家痛苦 研究游戏时长与幸福感无关_腾讯新闻](https://news.qq.com/rain/a/20260326A0750Y00)

  不是很好玩到后期，因为玩家的决策在被随机的卡牌否定，敌人是不变的。就算地图的路线也是随机化的。无非就是走火堆稳定收益保险，走问号规避小怪的血量消耗，然后打小怪拿卡牌，无法成型就在一阶段GG。



# 这个游戏带给你什么样的感觉？
+ 享受选择卡牌组成最优策略卡牌的策略成就感
+ 扮演铁甲战士不断冲击塔顶
+ 消磨时间

# 玩游戏时你具体在做什么？
+ 拿牌，怪物越后面强度高，没有最优解卡牌，没群伤，没高费，没运转是不能打到最后的
+ 针对怪物的状态，进行当前手牌的最优操作
+ 规划路线，选择去不同的地方

# 亮点
  对比一代就是你会体验到新内容，新的选择，新的卡牌，新的角色。

# 缺点
+ 这一代太吃群伤了，而群伤的卡牌如战士，很难遇到，至少我很难遇到
+ 我不知道为什么我一拿完美打击就不会出现佩尔的增生组织，我没招了，大概率有开修改器才能体验自己想玩的爽局
+ 抛弃旧卡牌，导致老玩家不好导致旧的策略抛弃，好想玩轮椅观者库库爽。

# 对比
## 《云顶之弈》
  与人博弈其乐无穷，两者的共同随机性和每回合选取卡牌组成好的卡组思路是一样的，不同点在于一个是有限的提升自己卡组来打掉敌人，一个是丰富自己的卡组思考更多的决策来存活最后。

  两者都是特吃运气的游戏，有穷尽的，你没有好牌，就赢不到最后，而云顶的优点在于一定能拖到3阶段才输，即游戏会进入到后期决出卡组优劣，而《杀戮尖塔》越后面阶段，没有好卡组=没机会=重开。

## 《小丑牌》
  《小丑牌》就偏的像云顶之弈，或者说至少你对挫败感不会特别强烈。或者我体验的不是很深。
