# 原型 / MVP / Alpha / Beta
这是游戏开发里常见的阶段划分，我帮你用一个“做菜”的比喻快速理解：

|阶段|类比|目的|你的项目目前|
|---|---|---|---|
|**原型（Prototype）**|用面粉和水捏出一个能看清形状的面团。|验证核心玩法是否成立。|**你现在就在这个阶段。**|
|**MVP（最小可行产品）**|面团烤成能吃的面包，虽然只有基础风味，但能吃下去且能判断“这个味道是否有潜力”。|让一小部分人玩到，获取“好不好玩”的反馈。|当你完成“敌人受击 + 简单AI + 状态机”后，就进入了MVP。|
|**Alpha**|面包有了馅料和更多的层次，但外形还不稳定，烤制时间也不固定。|内部测试，核心内容完整，但还存在Bug和未打磨的内容。|所有核心机制（战斗、敌人、基本UI）都实现，可以内部试玩。|
|**Beta**|面包配方和烤制时间都稳定了，只差最后的包装和细节美化。|公开测试（或接近完成），重点打磨体验和修Bug。|游戏内容完整，只剩润色和测试。|
