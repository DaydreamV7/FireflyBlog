# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">整体初印象与总评</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">关键词：休闲养成、自由探索、回归童年</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">总体评价：一款回合制战斗的开放世界探索满足童心的多人在线偏社交的游戏</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">加分项：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">游戏机制。它缝合的实在是太好了，就像是看到了《幻兽帕鲁》的成功而决定制作。游戏机制显得十分成熟，精灵的释放交互，利用精灵采矿，战斗，精灵坐骑。实现了当初2D状况下很多无法实现的功能和游戏体验</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">序章设计。当你完了《鸣朝》的设计再游玩《洛克王国》，你会发现新手的教学，序章的推进是很丝滑的过渡，鼓励新手使用游戏机制。且容易理解，我很惊喜一点点地解锁游戏机制和剧情交互，虽然老套但实打实地让人体验在这种偏童话般的剧情，缝合《哈利波特》的法杖，《口袋妖怪》的精灵，还有以前的提莫。</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">减分项：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">序章设计。序章设计后面就显得较长了，我是正常体验1.5h左右才解锁自由探索，感觉有点冗长了。</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">动画较长。我希望提供一个加速动画的功能，我似乎成了快餐玩家，对于战斗动画的固定让我重新体验到了《P5R》那不能跳过的结算动画，很浪费时间。</font>

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心玩法体验</font>
+ <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">这款游戏最核心的玩法有没有抓住你？它给你带来的核心爽点、最让你难受 / 无聊的点分别是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  作为开放世界它很好的承接了探索和收集这两要素对于《幻兽帕鲁》的对标来看待。  
</font><font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  核心爽点：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">精灵。美工，设计，交互。满足童年时期你所期望有个小伙伴在身边的感觉。</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">战斗机制。精灵的回合制战斗就是这么简单直白，上手快。</font>
3. 大世界探索。那么多的精灵，未知的地图，你需要体验的游戏内容很多。至少一开始不会无聊。
4. 剧情。WOW，是洛克，是拥有精灵的洛克。

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  难受点：</font>

1. 动画。其实是有小小的割裂感的，你用了共鸣这一功能强化技能，然后迪莫一个动画。最后实现的回合制战斗画面朴素无华，显得割裂。
2. 繁琐。至少在序章的后面设计我觉得有点繁琐了，好在不是特别长。

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">长线游玩体验</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">随着游玩时长增加，你对这款游戏的兴趣是上升、持平还是快速下降？你觉得影响你持续玩下去 / 想要弃坑的核心原因是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">上升。本身这种低年龄向的游戏受众较广，且这种一开始就需要充满探索的简单游戏机制的MMO是很容易进入心流体验。更不提它不错的游戏机制</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心原因：游戏机制。你会去抓不同的精灵，捕捉稀有的精灵，探索地图，养成精灵。</font>

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">游玩动机与情绪价值</font>

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">横向对比与最终定位</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">和同类型热门游戏 / 系列前作相比，这款游戏最大的优势和短板分别是什么？最终你会给它一个怎样的游玩定位（比如必玩、可玩、避雷）？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">与《</font>幻兽帕鲁<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">》对比</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">最大的优势：</font>

1. 基本盘。页游时期就有丰富的受众了，世界观，精灵等，很容易就融入进去，心流体验。
2. 游戏机制。至少不像《幻兽帕鲁》那样显得恐怖，因为它把营地功能和帕鲁机制绑定一起，导致循环出现了。而在《洛克王国》你更多的是养成精灵更多一点。去不断地探索，将精灵成长
3. 剧情。剧情立体化的表现，RPG游戏当然有剧情会更好玩。

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">最大的短板：</font>

1. 繁琐。这是游玩1.5h带来的感受，因为《幻兽帕鲁》的剧情占比很低，且过于直白，所以目前的短板就是繁琐，实际上你可以跳过剧情之类的。重剧情的玩家肯定会玩的久一点

游玩定位：好玩，当你游玩《幻兽帕鲁》觉得没有什么剧情，你需要养成你的精灵，设置想要社交人设其他有童心的玩家，你会很喜欢的。
