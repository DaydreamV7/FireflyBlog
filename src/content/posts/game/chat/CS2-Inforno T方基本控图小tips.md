# 炼狱小镇图形
![[炼狱小镇-地图.png|555]]
- 控图近乎1段。小镇的地图特性相较于沙二，是很少有长距离对枪的，偏中距离的地段仅香蕉道、中路、侧道。15回合制的小镇实际上侧道的博弈会重一点，但现在来说除了非常规套路和Faze烟中路前顶，侧道相对安逸。而且中路CT给中路烟是没有什么中路上的博弈。那么最重要的博弈地段就是香蕉道！
- CT回防时间较长。我记得在Hooxi、Jks时期的G2战队，虽然警方拿分少，但他们经常会通过T方回合来拿下这一图的比分。在那个时期我认为是匪图。而且经测，从连接回防到长廊向B点的末尾是需要10s的，10s你将面对警家烟还需要花额外时间移动到棺材，没什么可操作空间。Dust2都能警家甩B门局，沙地穿A过点。如果下的棺材包，你很难对包附近进行干涉不像远古遗迹。
- 道具小镇。道具的博弈很强，你会经常用A点的烟去帮B点吗？但是在小镇我倒是用得多。木桶火，三箱火，反清闪，黑豹闪等道具，控图基本是靠道具推进，没怎么见干拉的。
- 紧凑。相对紧凑和较多的短距离对枪，让野牛、内格夫、电击枪、喷子等武器持续发光发热。
# 默认开局
这默认非常不好讲，5个人的位置情况大抵如此
![[Pasted image 20260623203123.png]]
  开局20秒左右会在这些位置，仅供参考。因为由于有下水道2号存在，5号的位置是自由的作为掩护并衔接1号的进攻。但由于保守，基本CT会反一颗中路烟防止提速压中路，侧道会给一个VIP火后单玩也行。
  注意：
  - 1号要防止香蕉道前顶，扔完火只要小心灭烟即可，大多数会给中段、树位、凹槽相关道具。
  - 2号5号中路要防止前压或者大狙慢推
  - 3号要防中路Faze烟后的前顶中路或者前顶侧道，第一时间是不用看旋转楼梯的，除非你没丢VIP火，那就看Timing了。
  - 4号进行A2楼控图
很明显匪开局20s要拿下匪口、中路、侧道的控图。我想讲的是香蕉道还有侧道的控图，先讲最重要的。
# 香蕉道控图
  建议匪口贴左边，以防不是第一身位导致被中路狙给拿到首杀。
## 丢木桶火
![[Pasted image 20260623210914.png]]

  你随手丢第一颗木桶火，他炸任他炸，反正不被炸。他烧任他烧，反正烧不到。你仅仅只用了一颗火，就能够让对面的CT不前压，并且他们扔烟灭火会被你注意到，你会进行架枪。一开始的博弈就如此简单的展开且纯粹。

## 抢香蕉道一套
  这一套我是在B站学的，Navi也用过好像。但是他们的道具覆盖更猛，单人只需要一颗闪和一颗火即可。实现
  ![[Pasted image 20260623211519.png]]
  尽量让闪在黄色位置爆开，来闪白前顶石板的CT且不白自己，然后边跑边对着墙边缘扔火，尽量烧到凹槽。
  ![[Pasted image 20260623211816.png]]
  效果如下
  ![[Pasted image 20260623211958.png]]
  只要你像火仔一样，笑嘻嘻的干掉石板后，对枪沙袋后凹槽，还有木板后即可。但单人打这套抢点道具实际上是石头剪刀布战术。缺点如下
  ![[Pasted image 20260623212257.png]]
  1. 会被1号大狙强行直架而送出首杀
  2. 由于火没烧满或者枪械劣势（你是火仔他是Niko，你是吹子他是步枪）
  3. 黄墙CT，但概率较低
这个时候优化的话，可以让队友直架或者窗口闪，Jame闪来配合杀沙袋后，至于黄墙很少见自己判断。
  这单人一套基本是在判断对面道具少，Eco可以强行以个人能力咬下香蕉道这兵家必争之地。在低分段十分有效，高分段见仁见智。你要灵活使用你的控图决策，让队伍过渡到爆弹位。

## 香蕉道进点
首先要确保沙袋、木桶、石板、匪口附近的控图拿下，无敌人干扰。且没有黄墙烟，就算有仅仅只是修改道具决策。
![[Pasted image 20260623214153.png]]
  先封双烟，棺材烟和警家烟隔绝B包点，然后丢Blitz闪或者黑豹闪启动，补充警家闪来维护输出。对面又不是职业战队，又不是k3一箱反清闪，打黄墙，又不是Jamyoung在台下一梭子混烟。你可以看Tyloo或者玩预瞄训练，小心花坛上过渡道台下，清完一二箱再清三箱和死点。
  ![[Pasted image 20260623214730.png]]![[Pasted image 20260623214819.png]]
  打得干脆一点，直接一点不就行了吗？B点进不去我们再思考别的，拿下香蕉道控图，1分31秒，队友道具都没交几个，直接爆B呗。三箱火，一二箱火，，死点火，警家烟，棺材烟，Blitz闪，黑豹闪，随手一个警家上空闪，道具覆盖已经很够了。
- 断后的4号丢完闪就可以直架匪口过渡道木桶以防进点失败补枪。
- 2、3号完成道具覆盖去补枪。
- 1、5号前后自由发挥突破。
失败了就失败了，人家反清道具赌B点没招就没招，但是在默认控图，对方3A2B的情况下，你不要香蕉道了，搞得A点好进似的令人无语。

# 侧道控图
  我记得我当时是看Ropz的POV学的三板斧。
## 侧道红柱
  在队伍重心在香蕉道的控图上，或者中路有Faze烟展开，你可以选择在红柱这里左右Peek，来防止第一时间或者中期CT控制侧道，并通过下水道过渡到中路再到香蕉道。
  ![[Pasted image 20260623220238.png]]

## 侧道默认并到VIP下
控侧道的兄弟基本会的一套就是敲碎玻璃防VIP前顶过路房或闪击旋转楼梯给VIP火，再给右侧闪防止中路前顶来达到防止侧道送首杀。
![[Pasted image 20260623220015.png]]
![[Pasted image 20260623215654.png]]
![[Pasted image 20260623220405.png]]
然后就需要在右侧给个较好的闪光，一般控图压力较高的局是不会第一时间交中路烟，而是中路Faze来烟来支持CT的多种决策。要预防CT中路前压，并且以现在的竞技环境，队友不一定会说对面交了什么道具，要默认对面前压。
然后过渡到VIP下。
![[Pasted image 20260623220807.png]]
这里的好处是，中路CT不能够轻易察觉你，然后就是VIP上不能看到你，你只需要预防旋转楼梯出来的CT即可，中路由匪口队友带。待在这个位置的目的是：
- 防止旋转楼梯前压
- 作为香蕉道T方控图失败，控图去A的支点
  如果此时你察觉在中期运营后，T拿下了香蕉道，你就要小心旋转楼梯、小心中路、小心VIP然后后撤步走到下水道，通过下水道去香蕉道来进行爆弹或者补枪。
  如果你察觉到队友往中路L位走，这时候一般队友不会主动说和你一起排A2楼或者有走侧道的T，此时你单玩A2楼，或者借助队友的闪光上VIP清理过路房。
# 匪桥
  在匪桥一般是为了掩护走侧道的兄弟或者走旋转楼梯的兄弟去更好地控制过路房和A2楼。此时你只要站在匪桥的中段对木板的右下角进行穿点，留10发对VIP中间进行穿点防止有CT找你单挑。
  ![[Pasted image 20260623221700.png|642]]
  ![[Pasted image 20260623222658.png]]
  进行完穿点后，根据实际控图补位或进行个人决策即可。
## 侧道拿下第一爆弹位
一般侧道需要配合中路L位拿下连接近点和A1近点的控制权，连接直架居多，建议以非常规位和直架CT爆了
![[Pasted image 20260623222157.png]]
为了进A需要拿下中路近点，和A1还有过路房。很少有A2CT前顶的。如果A2CT前顶他与包点还有队友是割裂的，属于是非常规的前压。
# 控制香蕉道后队友决意打A
  书接上回，就算你拿下香蕉道队友不鸟你的控图战果你可以站立跳投个下水道259摩托烟来支援A点
  ![[Pasted image 20260623223044.png]]
  或者丢Device闪来辅助队友进A1，但执意打A一般已完成进A1。瞄准白色箭头尖尖站立跳投即可，让队友背相应位置的闪光或等闪爆即出。
  ![[Pasted image 20260623223205.png]]
还可以丢老摩托烟，再和A1队友配合。跟着描点站立跳投即可。
![[Pasted image 20260623223917.png]]

### A点博弈

![](https://imgheybox.max-c.com/web/bbs/2026/06/24/0cc7a7aefda5e68c9eb6d2ced7e9aab8/thumb.jpeg?imageMogr2/format/webp/quality/50/auto-orient/ignore-error/1)

  你是说开局30s，你在对面推烟的情况下，把木桶混烟还有前顶香蕉道的CT击杀了，在一个人把CT控B双子星monesy和京介干掉的情况下，A点四个队友全没了，包还在中路近点！

![](https://imgheybox.max-c.com/web/bbs/2026/06/24/93c4c6bf3386ce4960b2c4dfb1fb6705/thumb.jpeg?imageMogr2/format/webp/quality/50/auto-orient/ignore-error/1)

  A点的博弈，是要等香蕉道出结果再说的。对面还没封匪口烟，你道具都没扔就干拉连接和马棚，你怎么这么自私！个人英雄主义，单人完成B点控图，结果包还在对面手里，0-4的比分，我好不容易给队伍带来翻盘的机会你就这么送了！

![](https://imgheybox.max-c.com/web/bbs/2026/06/24/82b67f97cb91f4605ea83748e7316c3b.gif?imageMogr2/format/webp/quality/50/auto-orient/ignore-error/1)

![](https://imgheybox.max-c.com/web/bbs/2026/06/24/f20effad21392837ef2fe89fbe853eca/thumb.png?imageMogr2/format/webp/quality/50/auto-orient/ignore-error/1)

  你就先玩侧道，实在不行拿下过路房，看中路队友什么操作再进行配合，做合格的紫色。

  一旦你要打马棚，打连接。你就是在和A点交锋。这话看起来像废话，香蕉道警扔点道具还能退，博弈点还能转移黄墙。你跟连接、你跟马棚打，要处理两面夹击，甚至没逼退对面，请慢点打，丢点道具。不会打你不要干拉找连接狙对枪啊，送完连接，送过路房，送二楼，再送下去，香蕉道也得送。
# 结语
  写这种教学文章说实话太需要有感而发的情绪来支撑了，耗时较久。小镇是相对轻松充满乐趣的图，道具的博弈相当精彩，减轻了枪法上的分配，但玩久了会导致容易马枪。
  适合高强度对枪后来点直截了当的道具博弈，你也可以复刻波士顿Major的20秒转点。纯粹的香蕉道博弈，和练习道具得到的反馈是十分不错的。
  由于A2楼，中路进点烧马棚上下火，隔绝A1冲连接较为复杂所以本文没有提及，比较偏打得单机了，但好在道具小镇能够以道具配合队友。
  祝你获得基本的控图和队友沟通完道具直接梭哈进点吧。
