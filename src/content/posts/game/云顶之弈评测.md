# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">整体初印象与总评</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">关键词：紧张刺激、休闲娱乐、运气游戏</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">总体评价：太吃运气的有牌库机制的卡牌竞技游戏</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">加分项：</font>

1. 英雄联盟这么多年的世界观，凑羁绊是十分有意思的。德玛西亚、诺克萨斯，你会自然而然地关注赛季故事。
2. 你可以体验不同的羁绊，尝试容易搭配。
3. 只要不是特别故意的运营，基本能撑到4阶段分出身份，作为竞技游戏来延长玩家的游戏时间这一点挺好的这种保护机制设立。

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">减分项：</font>

1. 平衡度，很多情况你的羁绊也许上个版本很好，下个版本开削。本来好好的二星佛耶戈开局，结果大解锁时代暗影岛根本不强了。当时把8级升9级是76经验比9级升10级68经验还多8经验，直接开启盗宗时代。设计师很难把握住这该死的平衡。
2. 最优解穷尽，最优解就那么几个，适合无脑的就是约德尔了，运营思路简单易上手还不用担心别人卡牌，我暗影岛凑5神盾，门板全在别人手里我一张都D不到。盗宗时期你玩不明白就冰皮芬妮，现在是佐伊蚂蚱。出现最优解每一局都能看的到这上分阵容不带变得，而你没有D到心仪的牌直接被人家上分阵容干掉，打不过就加入，你也会用上的。
3. 运气游戏。运营运营没运怎么赢，其实阵容成型固定套路就那些，你得靠运气D到你想要的牌。基本和《杀戮尖塔》差不多。



# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心玩法体验</font>
+ <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">这款游戏最核心的玩法有没有抓住你？它给你带来的核心爽点、最让你难受 / 无聊的点分别是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  主要是你也可以尝试扮演不同阵营，加入虚空的变异，德玛西亚的荣光。当你拿到强大的卡牌用不容的装备去运营强大你的阵容，很好的。  
</font><font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  核心爽点：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">狠狠地殴打其他小小英雄的血量</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">3星4费小偷的快乐</font>
3. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">D出自己想要的牌</font>
4. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">以绪塔尔。当你玩以绪塔尔，才是真正的乐趣，是通过在场条件执行自己的策略，而不是得到什么牌之后按照当前版本的固定最优解看运气。</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  难受点：</font>

1. 因为是运气游戏，就算你运营的很好，但架不住你运不够，再怎么决策想要的牌不出也没有办法。这种无力感没招了。
2. 平衡度不够，当时冰皮芬妮还是弗雷尔卓德迅击战士，固定阵容把把见很恶心，正常玩暗影岛一张门板D不到太恶心了。然后在大解锁之前，斗士也很无脑，我只能靠约德尔上分。

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">长线游玩体验</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">随着游玩时长增加，你对这款游戏的兴趣是上升、持平还是快速下降？你觉得影响你持续玩下去 / 想要弃坑的核心原因是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">持平吧，更倾向于下降，因为卡牌游戏其实是偏休闲的。《杀戮尖塔》、《斗地主》当你有时间你偶尔玩会很开心，长时间下去，万一运气不好连输很令人不开心。</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心原因：运气游戏。最优游戏策略较少。</font>
