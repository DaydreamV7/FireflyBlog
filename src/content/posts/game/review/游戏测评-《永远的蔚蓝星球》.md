# 前言
  由于看到朋友圈有人推荐这款小游戏便进行游玩。
# 整体初印象与总评
  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？
  
  关键词：休闲、策略、随机、塔防
  
  总体评价：这是一款玩家没什么操作空间卖数值的小游戏。

加分项：
1. 精致的小游戏。它是一款优秀的小游戏，有一定的深度但不多，很精致。成熟的UI，卡通的画风，无论是免费道具需要增加你对付费内容的浏览亦或是红点指引你点击图鉴获得游戏道具来诱导玩家主动了解内容都是不错的设计。
2. 游戏机制。快速上手的游戏机制，普通玩家只需要了解游戏提供两个按键，一个强化，一个召唤。

减分项：
1. 策略不由玩家控制。《三国：谋定天下》都比这个的玩家决策要多。一个召唤跟2048似的进行随机合成，我为什么不玩《云顶之弈》？一个强化选择四个英雄当中的一个增强，我为什么不玩RougeLike比如《土豆兄弟》？发现玩不下去了。我要玩策略，动动脑子我也可以玩《植物大战僵尸》，塔防连放的位置都不可控。
2. 卖数值。卡关了就得搞数值了。国王、英雄、挂机、商店、免费资源、活动等，我得像个饕鬄一样过个遍获取游戏道具来增强英雄这个操纵角色，均衡的战力体现了数值的乐趣？
