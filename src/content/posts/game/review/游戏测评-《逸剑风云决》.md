# 前言
  感谢制作人GC小迪以及同样参与制作的人员，并由B站UP无实体介绍了游戏背后的故事。

# 介绍
  《逸剑风云决》又名 叔叔的好侄子南下中原开局中个毒不小心修炼保命神功，随后叔亡妹散，成为正道弟子，行侠仗义，打遍中原。最后回过头来发现自己叔叔的武功才是天下第一的《宇文巨侠传》。
  从秒天秒地大能巨侠，到享受贫下中农无产阶级再教育的侄子历险记。这是一款集人物养成，四处下乡，支持轻工业，穿衣绑法与叶家赛跑于一体顺带赠送传统武侠剧情的切磋大作。
  它讲述了主角宇文逸流落小村，小妹失散，行侠除恶，拜入武当，行侠仗义，发现武当剑法实在太弱小了，修习丐帮与少林功法，穿梭于江湖多少事之间，与人切磋，不断变强，回到武当继续切磋各师兄弟，请教武当功法，最后手握太极剑法，问剑江湖，各图挖矿采集，找人切磋，找人请教，顺便行侠仗义谈个恋爱，最后发现身怀绝世武功，却没有自己叔叔的武功强的成长故事。
  由此可见，行走江湖的本质是找人切磋，珍惜跌打酒，远离宇文逸。
  
  他，宇文逸，又名宇文巨侠。能工巧手，擅长拳脚，大胃袋。在少侠时期一身武当招式打人不疼，但业余爱好广泛，做衣烧饭，打铁炼丹，还是正道武林弟子，对干坏事的恶人重拳出击，然后给村民们疯狂跑腿，多少钱都干。

  战斗系统。棋盘回合制。玩家可以使用拳扇、刀、剑、枪棍，暗器五种体系，使用一式、二式、三式、绝式、轻功、心法来与敌人博弈。
  透过现象看本质，打不过一定是数值的魅力还不够，简单讲三招这个游戏打人一定赢的准备，第一扫光，搜罗地图上你能够搜罗的，矿材、药材，一个不留，鱼和食材大大获取。NPC包里的也别放过，然后炼制丹药，食物Buff通通进肚，打装备做衣服武装全身，用最好的准备实行最毒的打。第二获取功法，武当不行换用丐帮，丐帮不行用少林，少林不行推支线，支线不行推主线，武林秘籍在手，天下自然尽有。第三喊大哥，打不过的有你瑶姬姐姐殴打，一手玄火功法蛮对豺狼虎豹轻而易举，面对土匪山贼更不用怕。再不中，有你莫问大师兄伴你左右。如果遇到队友战怎么办？把队友装备扣下来。

  《逸剑风云决》展现了国产游戏的魅力，武侠独特题材的风格。走镖遇难、问剑六派、六派围攻、门派秘事、争夺绝世武功、塞北千军。游戏展示了成长、问心、携手、于黑云之前并肩，在风云中前进。宇文逸从小村小山，再到名门六派，从波谲云诡的阴谋，再到千军破关的威压，尽显吾道不孤和不负侠心的信念。
  虽然武侠的故事是十分套路的，从小地方成长，再到后来的拯救世人。侠在每个人当中都有不同的定义，但每个人在套路中都会问一遍自己对侠的定义，并不断地探索，验证，实现。

# 整体初印象与总评
  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？
  
  关键词：棋盘回合，RPG，武侠
  
  总体评价：这是拥有顶级剧情的RPG武侠游戏。

加分项：
1. 探索冒险。宝箱设计和丰富的支线会拥有独特的体验，对探索地图有着正向激励。在重复的跑图中不容易减小心流体验。
2. 剧情设计。庞大的剧情撑起了游戏的骨架，主线与支线相互交织。即使在我初印象看到有炼丹、锻造、制衣、采集会认为有很多重复刷的游戏体验，但其丰富的支线剧情设计让我更多的沉迷于跑图，而且庞大支线以及主线的剧情同样扣人弦线。
3. 数值设计。我对回合制游戏一直都是很少玩的，最近是去年的《P5R》但我根本就不想研究，而前期很难拿到“轮椅”从而促使我对请教系统进行研究，并不断提高自己的数值。战斗系统其实没什么好说的，我觉得重点是数值设计。
4. 引导。对于基础的功能比如战斗、采集等功能引导都不错，甚至安排了好兄弟卫霍。
5. 铁蛋。当我出新手村了解到抄书机制，“抄书四圣”的存在让我对NPC有一定的功利性也是挺让我开心的。就像《幻兽帕鲁》光捉不用也不太可能，这是让我感到开心的一部分。

减分项：
1. 数值设计。我当时为什么要坚持用剑啊，一周目用剑苦死我了，让我对其他玩家少林棍法和丐帮功法会心一笑。当中期拿到成型的体系（我是太极武当），基本就可以速过了。导致后期没什么很好的体验。
2. 部分弱引导。因为我是第一次游玩该类型游戏，我是真不知道要养欧阳雪，因为不影响游戏正常剧情流程所以我就认为这是减分项吧，我都没管队友了，中途看了下攻略培养“吕布上马”了，不影响正常剧情体验，没想到去养其他队友，再回头养又要好多时间。
3. 剧情再多点。这是贪心也是游戏的不足，欧阳雪我的确不能共鸣她为什么是女主，就和《败犬女主太多了》凭什么是“老八”。由于缺乏补充或者引导，对部分NPC观感不佳。还有瑶姬为什么不能提前找，发现没地名找不了有点遗憾。
# 核心玩法体验
（最爽的地方 / 最难受的地方）

核心玩法：体验剧情和探索并培养角色。

最爽的地方：
- 剧情体验。让我记忆深刻地有两处，一处是瑶姬的剧情表现，即使在后面的主线剧情都会有露脸并帮助主角，另一处是“天佛窟”。
- 人物培养。这是RPG的特色，从前面的憋屈到打扁天下无敌手，从会令玩家开心的。
最难受的地方：
- 数值设计。一周目我是没做完“武家旧事DLC”慕家然后去做主线，不完美是道坎在我心里。可初期打不过，中期一下子无敌了当我拿了云相太极，拿了武当三件套。就很快过主线了，因为其他一个队友都比初期的我能打，比如莫弃。我真不知道养队友，哪知道欧阳雪是关键NPC，我自然不待见。

可玩。

我没怎么玩过同类型的游戏比如《八方旅人》，但从剧情体验上来讲它的体验独特。对于《侠客风云传》是我以前云完的，不是限时的设计以及丰富的剧情是它的优势。

短板我认为是数值设计吧，每每想到出了武当回来都是少林棍法和丐帮掌法的其他玩家，我坚持用剑法就很der，真得哪个强玩哪个。

# 结语
  我怎么又写了这么久。
  
  总的来说我很感谢出现这么一款游戏，在我体验《空洞骑士》之后有了很好的角色培养以及剧情体验。对于RPG游戏要么游戏机制好玩，并且剧情不错才能是一个合格的RPG游戏。让我思考了我为什么会给它一个夯而不是和《赛博朋克2077》的顶级，是因为“2077”的结尾的剧情真不是我想要的，太憋屈了。而《逸剑风云决》就是这么朴素的用王道热血吸引我持续游玩。并且“碧海仙踪”的游戏剧情体验也十分不错，又减少了肝度。
  
  另外这个作品成功地让我把目光转移到其他的游戏和其他的题材。比如《大侠立志传》（很遗憾它的新作风评）。我要不要玩老游戏《仙剑奇侠传1》呢？但它给了我很大的游戏戒断反应，短时间真不想花太多力气沉浸游玩了。
  我会持续期待国内独特题材武侠相关的游戏。

  祝大家好运。
