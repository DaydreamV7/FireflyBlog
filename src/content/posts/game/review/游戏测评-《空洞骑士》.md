游戏时长：24h
进度：干掉三个守梦人
从夯到拉评价：顶级
# 前言
  感谢樱桃工作室。
  依旧是好玩的游戏确实好玩。
  对于我最重要的展现了独立游戏的设计吧，还有他们的举措所展现的纯粹的“独立游戏艺术”。
# 介绍
  《空洞骑士》又名 小虫的奇妙冒险。
  武林秘籍不是骗人的，掉下悬崖真的有奇遇。
  你将领略圣巢的阴险狡诈，在十字路上下左右BABA的探索，看到了电车却没有票而上不去，看到了幼虫却跳不上去，不断地进行广度探索。前方有路不能走，地狱无门到处走。
  花样的战斗。学会“波动拳”，学会“二段跳”（哇！是二段跳！），学会冲刺，学会“战争踩踏”，学会“吼叫”，不断地进行各种各样的战斗。什么？你用的是朴实无华的普通攻击？
  奇妙的NPC。为了卖地图随地乱丢卷子的地图商人，八分娜娜的一份地图拆着卖得便宜商人妻子，收藏的，说书的，被救的，打铁的，徒弟三人和师傅一人的，奸商！你个灯笼怎么卖这么贵！
  以及各种小怪和Boss，抡大锤的，“吐痰的”，“丁真的”，“不要脸的三连发”，追踪导弹，丢旋转刃追着杀的螳螂。
  最后拿起你的骨钉去改变圣巢。
# 整体初印象与总评
  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？
  
  关键词：2D动作，超快节奏战斗，探索冒险
  
  总体评价：以探索冒险为主要乐趣，用Boss挑战丰富游戏的，2D动作冒险游戏

加分项：
1. 探索冒险。开局一把骨钉，想要都得捡，不断地去探索和解开游戏内容，获得技能，作为冒险游戏是十分合格的。且地图商，解锁区域的奖励都不断地激励玩家进行后续的游戏流程。
2. 地图设计。当你主动了解樱桃游戏工作室设计的故事剧情，你会为它们的为了故事而进行的关卡设计十分奇妙，其地图的关联，中后期非线性的探索，总会让玩家有不同的想法，也会想要见到不同地图的不同故事。会发现，原来这里有隐藏地图，原来这里可以这样上去等探索体验。
3. 战斗系统与敌人。通过徽章来不断丰富战斗的多样，有“打铁”，有场景交互（攻击地刺和板子），法术，剑技（虽然不怎么用）。对敌人会有不同的打法，有更多的想法。头一次了解到“蛆流”。即使打败敌人，我也会看着其他玩家的视频思考“打铁”的游戏战斗体验又是怎样的？

减分项：
1. 超快节奏战斗。高密度的玩家决策会上手难度较高，且部分敌人比如“灵魂大师”的砸地我得以横向移动来解决，但仅1s左右的间隔我需要进行重复动作，因为这个是连续的。会导致重复度较高，玩家需要高度集中。我想表达的不是这样不好，作为刚接触超快节奏2D动作游戏，大部分我是用数值和较低的决策如《死亡细胞》来解决敌人，而作为超快节奏战斗的《空洞骑士》虽然它设计了小怪来提前透露Boss技能，但我优先思考的是躲避而不是攻击。作为死亡的惩罚我就得进行“跳跳乐”并有可能削减了一些HP才能进行重复的Boss挑战，红温啊！椅子！而且基本上敌人身上都有碰撞伤害。相较于《只狼》我觉得节奏更快，连贪血的时机都较少。如果让我推荐快节奏战斗游戏，我不会首先推荐《空洞骑士》给朋友玩，而是《只狼》。至少玩家要进行决策的时候不会那么窘迫。出生叛徒螳螂！
2. 弱引导，玩家必须在十字路找到地图商，才能够建立起核心动力“解开地图迷雾”，并不断地探索地图里的其他场景。在游玩到后面迷路的情况，我不禁感叹，“即使引导早已破碎，也请您当上艾尔登之王”。补充：我突然想到战斗理由了，我第一反应是“它阻挡了我探索后续的路了”。其他游戏会给比较弱的正当理由，比如“成为艾尔登之王”，“斩妖除魔”，“荒野大镖客2我本是匪”，而《空洞骑士》是在安息之地才能得到引导，而瘟疫又不如“丧尸”显得直观，虽然有的虫跟“丧尸差不多”，所以我对打倒Boss没有多大的倾向。而是想继续探索游戏内容。
3. 游戏内容解锁较慢。在打赫拉之前，我想想。我是在探索王后花园除了赫拉那块地还有王国边缘地图还有悬崖地图没开。其他都开了，货币我一般用来买纹章和提升角色的物品。到了我了解“小偷银行家”我才有了一笔巨款把灯笼买了，没有灯笼有好几个区域路过没有探索，废了老长时间探索，但收益实际上我认为不是很高了到后期。还有那个电车证，我是解开了赫拉地图区域后才去废弃电车区域拿的电车证，那没什么运用的空间了啊，因为当时看深渊巢穴里的小怪较强我一直没敢探索，直到最后才拿到的电车证没用了。刚玩我拿个初期的某个道具“城市纹章”或者“典雅的钥匙”，去了两趟电车站没有反应而作罢。
# 核心玩法体验
（最爽的地方 / 最难受的地方）

核心玩法：探索圣巢的隐秘，不断战斗

最爽的地方：
- 不断解开迷雾和探索地图，一点点地打败Boss
- “螳螂领主”！打三螳螂，既有一定的决策思考，又打得有来有回，打赢螳螂给我鞠躬，太爽了！
最难受的地方：
- 椅子！这Boss不带停的！我不想“跳跳乐”！

# 横向对比与最终定位
和同类型热门游戏 / 系列前作相比，这款游戏最大的优势和短板分别是什么？最终你会给它一个怎样的游玩定位（比如必玩、可玩、避雷）？
可玩。
可以看我的“整体初印象与总评”，

对于冒险相比《幻兽帕鲁》：
  幻兽帕鲁主要是以帕鲁为核心而展开的营地，采矿，探索，词条等系统，探索冒险的收益相较于《空洞骑士》要更具有激励。而后期基本会意识到是重复的游戏行为，一个是帕鲁，一个是战斗。当意识到重复之后，我不太能够接着进行游玩。即使我知道游戏内容还能接着玩。而《空洞骑士》就是剧情所关联的地图探索的差不多了而导致重复，两款游戏是相似的，但《空洞骑士》还有更多的战斗内容来丰富，还要收集“梦碎片”解锁游戏内容。
  
对于动作和战斗系统《只狼》：
《艾尔登法环》我拿轮椅武器过的。所以拿《只狼》讨论。
  超高节奏的战斗我认为是和《只狼》区别，《只狼》是可以进入一定的战斗间隔来缓冲，作为新手可以在较广的区域进行战斗策略，无论是逃跑，躲一边喝药，疑惑是闪避，跳跃，攻击，都是相对于《空洞骑士》较慢的，有一种我再撑一会能打过敌人，我还能再活一次。而《空洞骑士》的快节奏，我必须在短时间进行战斗决策，不然就要削减HP。虽然重复战斗我会不断地思考如何打过敌人，如何躲避攻击。但我更容易红温，从设计上《只狼》的血条和《空洞骑士》的血条格是不同设计，只狼会有“我还活着”，而《空洞骑士》会更看重“HP格”，少了几乎很难恢复回来令玩家感到紧张多添一份无奈。
  
# 结语
  我应该不会进行后续游玩了，我已经连着沉迷4天以上了，但当我拿下赫拉，没有什么欲望了。可能我确实不是该游戏的受众，虽然我知道还可以进行梦境探索去殴打它们的梦。
  还有很多事要做，还有很多要去探索。

# 补充
我突然在思考游戏性。

给予我基本地游玩体验是地图迷雾给的，虽然中间穿插着“支线”比如“小偷银行家”，其他的道路例如不断探索找到爱之塔需要钥匙，那么作为第一次游玩的我能够确定的就是地图探索。当地图探索结束非常自然地导致我没有游玩的动力，紧接着我查攻略玩准备实现结局三获取梦境碎片。

在中间我去了解《空洞骑士》的故事以及《丝之歌》的故事，可回到游戏，我没有动力即使我知道还有很多游戏内容比如格林剧团，但剩下等着我期待的只有战斗了，可我不期待战斗。

另一方面说明有些游戏做了引导比如《艾尔登法环》，或者游戏内置的人物系统是有一定作用来帮助我进行游戏行为的。

至于场景变化像十字路的变换与《只狼》的场景变换作用差不多，我没有感到惊艳所以没加入到加分项。

兴许我得接着游玩不断战斗去发掘更多的游戏性。我兴奋吗？我保持质疑。

哦对了，我突然想到了和《只狼》的区别，比如攻击能实现水晶踏板的反转，以及攻击地刺。这作为场景交互上是比较新奇的。可是我一开始的认知是不能攻击，更进阶的技巧需要玩家去探索，这是它的魅力可我已感受不到接受新反馈的乐趣了，乐趣是相对的比如《泰拉瑞亚》的“牢房”。
