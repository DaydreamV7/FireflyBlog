游戏时长：17.2h
进度：掌控岛屿军队和25级左右的部落（没细研究）
从夯到拉评价：人上人
# 前言
  我应该缓一会再玩战争之影的，太快马加鞭不是好事。
# 介绍
  《中土世界：战争之影》又名《半兽人宝可梦》。
  
  战斗吧，我的半兽人队长！
  
  这是一款核心为抓半兽人，养半兽人，去和其他半兽人PK吧的半兽人宝可梦游戏。至于原来的游戏体验我们一笑而过即可。半兽人为奴？不不不，半兽人又不会像帕鲁一样为我们干活，它只是斗蛐蛐中的一部分。
  
# 整体初印象与总评
  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？
  
  关键词：技能树，半兽人养成。
  
  总体评价：成为ARPG刷子游戏了。

加分项：
1. 半兽人系统：就是奔着这个玩的，在前作的基础上更加丰富，还能实现“斗蛐蛐”。
2. ARPG游戏基本：作为一个ARPG游戏，它继承了前作的系统，丰富了原来的技能树，丰富了半兽人系统，增加了三四个部落来丰厚了游戏进度。
3. 救星系统：哇塞，这个设计给了我意外之喜。它比第一部的保镖给我的感受更加强烈。当我21级去挑战38级甚至45级的半兽人队长，面对恐怖的伤害和机制，还有我提高了游戏难度（普通感觉简单了），再加上刷出来一堆的特殊半兽人。纵使我一堆技能，我也会被群殴或者等级碾压而死。但是，在我打不过Boss可能要卡关的时候，救星来了，23等级的半兽人队长一棒子把高等级给打死了别提我多开心了。赵云来了！

减分项：
1. 剧情：（写到这里我脑子里只剩下它的负反馈了），第一幕太长了，我用了3h+，我本来是想要快速解锁军队系统的，因为本游戏最大亮点就是“半兽人斗蛐蛐”。3h+，剧情我也不是特别喜欢，相较于第一部的过渡显得不是很自然，且废时间。“卡南的幽灵”的剧情我不是很喜欢，是错就是错，要承担责任就承担责任，下马威就下马威，怎么鼓弄玄虚，说话不直接拖这么久，该干的活又没少它的。
2. 敌人太多：太多了，因为大部分半兽人队长在堡垒里面，有刷怪很正常，群殴也行。我十八般武艺。处决、反击、远程攻击、匿踪击杀、精灵暴怒、保镖、放毒、放火、放冰、骑野兽都来一遍怎么就打不死你这个半兽人队长，还有一堆防空的、防远程的、防近战的、大型霸体的、远程攻击比第一部频繁的半兽人。我怎么打？我把小兵灭了又刷过来，再加上伤害可观，我不能一打多我认了，第一部我是可以一打多的呀。奥罗格多的令我陷入疯狂。
3. 技能树不佳：相较于前作没有大的战斗系统改动，加了精灵暴怒，没什么令我印象深刻地技能，也因为我为了快速过渡到军队而忽略了教学，我没有想到技能升级只能选取一个，这就很不爽了。与其说是ARPG，我觉得更倾向于RPG，它重要的不是A，而是数值。技能树的加点收益到我这个游玩阶段不是很佳，而通过其他玩家和攻略我了解到了流派，还需要研究。
4. 半兽人队长战前宣言：第一部很简短明快，出来一个半兽人队长说一句话拖个15秒左右，这和《女神异闻录5》不能跳过的战斗结算“萨斯尬酒卡”有什么区别？“萨斯卡半兽人队长”，放垃圾话也这么专业，“半兽人意志”这一块。
# 核心玩法体验
（最爽的地方 / 最难受的地方）

核心玩法，它的核心玩法是半兽人军队系统。

最爽的地方：
- 支配兽人，挑兽人，养兽人，支配兽人。
最难受的地方：
- 剧情。它拖慢了我军队系统赶紧端上来。
# 长期游玩体验
随着游玩时长增加，你对这款游戏的兴趣是上升、持平还是快速下降？你觉得影响你持续玩下去 / 想要弃坑的核心原因是什么？

持平。

  核心原因：半兽人系统还是太棒了，在我建立军队不断地进攻半兽人堡垒，被击杀也会因为复仇机制而持续游玩。在前面由于剧情的原因导致游玩不爽的情况下解锁半兽人军队又让游戏更丰富有趣了，而后面独狼打不过很烦的情况下出现救星狠狠地给我的心流扎了一针强心剂，又能爽玩下去了。

# 游玩动机与情绪价值
  你玩这款游戏最核心的诉求是什么（比如策略成就感、消磨时间、剧情沉浸、社交互动、操作爽感等）？它有没有满足你的预期？游玩过程中正面情绪和负面情绪的占比大概是多少？

最核心诉求：接着品味游戏，看看“半兽人斗蛐蛐”怎么回事。

正面情绪和负面情绪的占比：6/4
# 横向对比与最终定位
和同类型热门游戏 / 系列前作相比，这款游戏最大的优势和短板分别是什么？最终你会给它一个怎样的游玩定位（比如必玩、可玩、避雷）？

我觉得要和前作《中土世界：暗影魔多》相比，
最大的优势：
- 半兽人系统中的“斗蛐蛐”。它放大了它最核心的游戏机制，这也是我在第一部没有品位过久的系统的遗憾。
最大的短板：
- 重RPG：第一部的体验让我对半兽人能够有从容的应对，而到了本作，我只能通过提升数值才能获得更好地游戏体验。
