# 整体初印象与总评

用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？

关键词：galgame(美少女游戏有美少女啊)、剧情向、恐怖
总体评价：这是一款以剧情为核心的galgame。主要的核心体验是剧情还有它的恐怖氛围略带点病娇人物设定。
加分项：

1. 恐怖元素。作为第一次游玩galgame向的恐怖游戏，它做到了剧情为主要的核心体验，恐怖元素的占比不是很高。
2. 剧情。它讲清楚了核心的世界观和角色的相应设定，有不错和及格的剧情体验。
3. 好看。galgame虽然是一个3D建模，但耐看。
4. 缓冲小游戏。小游戏设计实际上是推进主线流程的缓冲，通过一些小游戏的进行来缓解恐怖要素，链接游戏趣味性维持心流体验。
   减分项：
5. 赶工。就是体量还是偏小的，有的地方明眼看出来要单一流程重复进行3次，不进行3次又不够丰富游戏内容，从结尾来看，开发只靠两个人来，我没有了解游戏开发背景，所以我认为体量相对来说是小的。52r的Steam国区定价挺合理的。
6. 出戏（剧情方面）。实际上它的背景世界观较为还好吧，因为是游戏，甚至展现了工厂流水线制作的"米塔"，所以共情我不太能够。

# 核心玩法体验

（最爽的地方 / 最难受的地方）
核心玩法，它的核心玩法是剧情。其他方面总的体验来讲是辅助和拓展因素。
最爽的地方：

- 无限走廊里面，当我看出关卡设计，一棍子敲碎那个蜘蛛脑袋是很爽的。
  最难受的地方：
- 类似《小小梦魇》的“木头人”关卡，感谢互联网开源，它设计的很密集，不死几次是无法知道劣质品的站位，而导致跑不过他们，本来想调高灵敏度玩旋转的（小小梦魇），感谢后撤步。

# 长线游玩体验

随着游玩时长增加，你对这款游戏的兴趣是上升、持平还是快速下降？你觉得影响你持续玩下去 / 想要弃坑的核心原因是什么？
缓慢下降
核心原因：剧情。因为到走廊那个关卡我就明白了这款游戏是重剧情游戏，如果不是为了推进剧情，它恐怖游戏因素占比不高，且小游戏过多，那么游玩丰富好玩的游戏机制并不是核心体验。而它的剧情首先是世界观不太好共情，其次就是无法反抗的男主不是我的喜好，然后就是为了丰富游戏时间而导致的单一流程重复进行3次。如果是很好的剧情（吸引我的，每个人有不同偏好）或深入体验，沉浸并积极推进剧情。

# 横向对比与最终定位

和同类型热门游戏 / 系列前作相比，这款游戏最大的优势和短板分别是什么？最终你会给它一个怎样的游玩定位（比如必玩、可玩、避雷）？
同类游玩的游戏有
galgame:

- 《甜蜜女友3》
- 《变态监狱》
- 《青春恋爱物语果然有问题》（视觉小说）
- 《寻爱或赴死》
- 《宅男的人间冒险》
  最大的优势：
- 就是它贴的标签，“恐怖”。通过这个标签来吸引玩家游玩，并得到别样的galgame游戏体验吧。
  最大的短板：
- 剧情。详细见上面。它最后实际上让我代入到了世界观，但结束了。我得去通过视频平台去了解，不太想再次游玩。

这里我想描述与同类型游戏类比：

- 首先它有点偏病娇文学，一直想让男主陪她旁边。我还没有详细了解背景和故事细节，所以不太喜欢，结尾我认为她是残次品，套别人皮上位。这么狂尽然没有得到反抗，太离谱，我更喜欢“若叶睦里的大莫老师”。
- galgame。既然定位是galgame，实际上剧情还不如《甜蜜女友3》的“鸿砂佑”线的剧情体验，但2人制作，能有这个程度不错了，点名《日薄西山》![日薄西山](/public/assets/images/game/日薄西山.png)更短！
- 对标《宅男的人间冒险》，它的小游戏是你推进剧情主线的一步，所以它的小游戏是加分。而《米塔》的小游戏你只是陪“米塔”去玩，而恐怖关卡才是推进游戏的主要流程，所以从正向的角度来说它更galgame，但《米塔》是需要恐怖因素的，看每个人的喜好吧。
