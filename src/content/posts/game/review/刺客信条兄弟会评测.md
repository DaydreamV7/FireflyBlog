# 背景

  我已经玩了14岁左右玩了《刺客信条》艾吉奥三部曲。云视频看了了《刺客信条3》、《刺客信条：黑旗》、《刺客信条：大革命》，看完了《刺客信条：兄弟会》同名小说。
我很喜欢《刺客信条》艾吉奥，他是我“复仇记”的启蒙。

# 整体初印象与总评

用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？

关键词：复仇、剧情向、狂战士
总体评价：这是一款在单一地图里面不断战斗、跑酷去推动主线剧情的AVG游戏，为什么认为是冒险游戏，因为大部分是在剧情里面穿梭。
加分项：

1. 连杀机制。变态的连杀机制，刺客大师艾吉奥除了因为任务的限制导致是刺客，熟练的我已经是狂战士了，杀进去狂战就完事了。
2. 剧情。艾吉奥魅力时刻，实际上剧情你再深思实际上还是简单了点，但是尼克拉和盗贼拉的误会，还有凯撒的执着都是不错的刻画描写，更不用提克里斯缇娜的心碎任务（但我还是喜欢威尼斯的罗莎）
   减分项：
3. 赶工。作为育碧的商业化游戏，我没有去调查它的商业背景，但很明显它比较仓促，地图局限于罗马，相对来说少了，我玩了一整天发现游玩内容快结束了，此时我养的刺客才9级还没升满。
4. 跑酷机制BUG，靠北啊，那个剧场任务刺杀4个火枪手，我要么不小心掉下去摔死，要么莫名其妙提前被发现，因为摇杆漂移在草堆里面出来。

# 核心玩法体验

（最爽的地方 / 最难受的地方）

继承刺客信条2的玩法和游玩体验，很好。本来就是奔着建设罗马兄弟会去的，可惜CG诈骗，没有感受到千军万马避白袍的游戏场景，且刺客养成属于我赚钱的一部分了。

- 最爽的地方：
  当我在波吉亚的那座城堡的那座桥的附近受到敌人的追击情况下，利用连杀机制击杀非常多的敌人
- 最难受的地方：
  刺杀4个火枪手还有一开始的火炮，让我感受到了Bug育碧的威力，奇妙的跑酷吸附还有敌人警戒机制，火炮不用键盘微操根本就不好通过

# 长线游玩体验

随着游玩时长增加，你对这款游戏的兴趣是上升、持平还是快速下降？你觉得影响你持续玩下去 / 想要弃坑的核心原因是什么？

持平。我主要是没想到快玩完了，推动剧情就是很开心，作为艾吉奥去复仇，去解决凯撒的统治，去抢走金苹果本就符合一个刺客该做的。

核心原因：剧情。

你玩这款游戏最核心的诉求是什么（比如策略成就感、消磨时间、剧情沉浸、社交互动、操作爽感等）？它有没有满足你的预期？游玩过程中正面情绪和负面情绪的占比大概是多少？

# 横向对比与最终定位

和同类型热门游戏 / 系列前作相比，这款游戏最大的优势和短板分别是什么？最终你会给它一个怎样的游玩定位（比如必玩、可玩、避雷）？
最大的优势：

1. 引擎升级。为什么因为在意它的升级，因为玩《刺客信条2》太老了，导致很多小细节让我觉得麻烦比如设置里的一些选项，还有剧情的跳过之类的。
2. 剧情。即使是这样的剧情都比一些其他的游戏要强！有铺垫，有矛盾，有冲突，有细节。而不是无理取闹，莫名其妙。
3. 游戏机制。依旧跑酷+战斗+暗杀三合一，且连杀机制太棒了，不耽误我推进剧情。且还有刺客养成。实际上

最大的短板：

1. 游戏时间少。我最近才知道原来有部分玩家在想买了一款游戏要玩很久，一下子没了嫌不够玩。
2. 游戏关卡落后。以现代去评判它的跑酷系统和墓室追逐战设计，太预制了，为了丰富游戏内容，硬生生将同一个关卡设计设计三遍，不重复三遍不能推进剧情，比如杀那个法国士兵避免被识破。

# 结语

我写的太匆忙了，但大致意思就这些了。
首先艾吉奥三部曲是非常优秀的游戏作品，《刺客信条：兄弟会》的定位类似《刺客信条：叛变》从内容上来讲。刺客信条2你会推进剧情而不断成长，而育碧通过“一炮回到解放前”巧妙地将艾吉奥推入了陷阱并加入了下级刺客刺杀机制，完成重建罗马。
但我会觉得不是很重剧情的玩家会因为单个地图的游玩显得觉得内容少，且由于不推动剧情，部分地区是不能进入了遭到限制，导致我游玩到这个程度还有三个波吉亚势力的塔楼没有解决。
如果你是刺客信条系列的玩家，我依旧推荐玩《刺客信条：兄弟会》，去体验艾吉奥的中年，去做罗马刺客大师。
写完了，不写就真有点不太想写了。后续再优化内容吧，但作为评测足够了，可惜深度不够，我再补点。
作为《刺客信条2》的续作，它就是赶工作品，它是可以花费点时间让重新体验过刺客信条作品的新玩家进行简单的游戏教学，但他并没有这么做，而是以Animus训练的弱引导来让新玩家熟悉游戏，它确实是一款粉丝向作品的定位了
