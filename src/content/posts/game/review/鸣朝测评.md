游戏时长: 1h  
游戏任务等级：3

从夯到拉：顶级

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">整体初印象与总评</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">关键词：爽快打击、狂战士、探索世界</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">总体评价：这是一款RPG要素战二次元受众的游戏，</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">加分项：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">战斗机制相对于《原神》是丰富一点的，首先失衡机制显得直观，然后处决动画的表现（但是同学说后期根本没有这个）</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">剧情有自动播放，跳过，对话历史等</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">减分项：</font>

1. 剧情。似乎国内的二次元游戏剧情云里雾里太常见了例如《AI LIMIT 无限机兵》。
2. 突兀的序章设计。关卡引导部分是比较长的，再加上并不是很好的剧情设计，比《赛博朋克2077》的引导要显得不够直白，不好进入心流体验。

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心玩法体验</font>
+ <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">这款游戏最核心的玩法有没有抓住你？它给你带来的核心爽点、最让你难受 / 无聊的点分别是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  我觉得它的战斗设计相对于《原神》来讲至少丰富的不错，前期不会显得太靠角色的数值，可以闪避，反击等攻击手段来对敌人进行攻击  
</font><font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  核心爽点：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">当我扮演漂泊者释放技能攻击敌人，协同攻击，反击，完美闪避挺好的。</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">战斗机制。残像很简单地拓宽了战斗决策设计。</font>
3. 女角色较多吧

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  难受点：</font>

1. 剧情。很明显游戏的受众偏成熟群体。如果是《原神》这种当初的媒体基本是说与《塞尔达：荒野之息》来对标。但是它的简单的战斗机制和大世界交互机制还有剧情设计，是受众广的原因。而对于像我这样的看过《叛逆的鲁路修》、《刀剑神域》、《为美好的世界献上祝福！》就会显得低端。低端在于云里雾里的世界观介绍，不够丝滑的设定输出，还有专有名词过多。像新手村主角太轻松的被接待了。
2. 独特性不够。六州六岁主很容易让我联想到《原神》这款游戏，漂泊者对应旅行者，但是开发世界RPG的信标和快速移动当然不在这种讨论中。
3. 优化。140多G，太狠了。

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">长线游玩体验</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">随着游玩时长增加，你对这款游戏的兴趣是上升、持平还是快速下降？你觉得影响你持续玩下去 / 想要弃坑的核心原因是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">快速下降。我现在不是国内二次元开发世界RPG游戏受众了。</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心原因：剧情和战斗机制。很明显作为网络游戏他的核心售卖点是：角色和数值。那么它的战斗机制肯定以数值为主。而以数值为主的RPG游戏能吸引玩家游玩的核心要素亘古不变的是剧情。</font>

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">游玩动机与情绪价值</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">你玩这款游戏最核心的诉求是什么（比如策略成就感、消磨时间、剧情沉浸、社交互动、操作爽感等）？它有没有满足你的预期？游玩过程中正面情绪和负面情绪的占比大概是多少？</font>

RPG游戏的核心诉求是：剧情沉浸。

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">横向对比与最终定位</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">和同类型热门游戏 / 系列前作相比，这款游戏最大的优势和短板分别是什么？最终你会给它一个怎样的游玩定位（比如必玩、可玩、避雷）？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">与《</font>原神<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">》对比</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">最大的优势：</font>

1. 特殊的受众。和原神不一样的美术风格能得到差异化的体现，也能得到不同的受众粘性。
2. 战斗机制的丰富。至少战斗决策不会像原神那样简单

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">最大的短板：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">剧情。剧情没有吸引我去游玩，意味着它的受众群体，或者它的剧本不够优秀，以《</font>消逝的光芒<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">》剧情体验会吸引你玩超过1个小时而不是靠序章强行绑定。其实你思考一下《原神》的前期序章设计。旅行者是被击落在提瓦特大陆的。然后通过救派蒙自然而然的得到了向导，这种其实是偏童话和小孩一点的参考《口袋妖怪》的皮卡丘。而且自然而然地过渡到了蒙德这种偏向骑士风格的国度。而相应的你会觉得《鸣朝》的序章设计挺刻意，生硬。</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">网络游戏。我还没有评测游戏的肝度，任务强度，还有消费点。所以不够全面评价。但作为网络游戏意味着它要充斥这些。</font>
3. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">优化。130多G。</font>

游玩定位：可玩，当你游玩《原神》或者喜欢偏现实一点的3D美术风格的开发世界RPG游戏。
