# 介绍
  《中土世界：暗影魔多》又名《刺客信条兄弟会之中土世界》。
  从经典的苦大仇深的反派Boss杀死全家结果自己未死的复仇记，到斗之气三段从零开始的技能成长，以及药老作陪无限信仰之跃畅游世界，再到兽人做我奴隶的下克上。
  这是一款集世界探索，复仇剧情演绎，技能成长，然后得到超级无敌戒指去奴役半兽人攻打最终Boss的爆米花大作。
  
  它讲述了一个主角塔里昂为了复仇和弄清真相，在发现由于有“药老”凯勒布里鹏的存在，自己堂堂游侠统帅却遭受斗之气三段的结果，不断重新学习技能，集结其余力量对黑恶势力进行讨伐。期间还要遭受凯勒布里鹏的追随者咕噜的嘲讽，以及栽培有趣的“怪胎”。最终为了建立军队击败最终Boss，不断在半兽人中摸爬滚打，沉迷打半兽人，奴役半兽人，被半兽人杀，抚半兽人的头，拿到半兽人的小秘密，复仇半兽人循环。再偶尔射射箭，摘摘草药，完成小训练，最终复仇成功的故事。
  
  由此可见，兽人永不为奴，半兽人一直为奴。
# 整体初印象与总评
  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？
  
  关键词：技能树，半兽人养成，复仇。
  
  总体评价：这是一款拥有丰富的技能成长的ARPG游戏。主要的核心体验就是跟半兽人拉拉扯扯。

加分项：
1. 爆米花般的游戏体验：“由J.R.R.托尔金笔下的《指环王》中的奇幻大陆“中土大陆”为背景改编而成。故事设定在了《指环王》之前”，但就算不知道《指环王》的剧情也依然不影响剧情体验，且剧情模式的张弛有度。就是很遗憾核心的军队系统需要剧情进行过度，但作为初次体验游戏内容的玩家，会自然而然随着游戏的吸引得到新的游戏机制所带来的惊喜感。玩家放松可以打造军队，玩家追求通关能够去推进主线。整体的流程给我感觉非常爽，如同《热血无赖》，可惜《热血无赖》的剧情太短了，也没有这个半兽人系统。
2. 技能成长：作为一款RPG游戏，主要敌人半兽人实在是太多了，面对游戏的难度你会自然而然地实现技能树的成长，且技能对战斗的体验在不断的增加，是合格的ARPG游戏。
3. 半兽人系统：非常自然地说明了游戏的挑战目标并不仅仅是最终Boss，而是用半兽人作为主要的游戏体验和战斗体验的维持。有战前宣言（简洁明快），有不同种类的半兽人，半兽人队长这一特殊的Boss机制。让玩家不断地向上挑战。并且复仇机制让玩家想要继续挑战半兽人队长。通过了解情报能够更好地对敌人的弱点进行攻击。
4. 剧情设计：咕噜和“怪咖”的设计让我觉得亮眼，因为复仇剧情实际上太多了，很容易腻，在中间穿插了咕噜这一凯勒布里鹏的“舔狗”，以及“怪咖”的奸诈中却知道如何呼唤利益的小人物刻画，最后的矮人一起击败巨兽的“兄弟情”。这都是精彩的剧情表现和人物刻画。在展现这个游戏世界的精彩，维持着玩家的心流。

减分项：
1. 半兽人系统缺陷：这算是一个轻微的减分项，主要是剧情体验是不错的，且第一次游玩半兽人系统也玩的很开心。军队系统靠后了。不能早点体验到，我急切啊。而且为什么我不持续打半兽人了，是因为技能点差不多了，且打半兽人不进行死亡宣告导致没有非常好的收益，再发现这个爆率太低了，推进主线主要靠技能点，那么普通模式就没什么必要去刷这个爆率低的半兽人队长了，结果发现军队系统之后我也会更倾向于把半兽人收的差不多了再进行攻打，本来就一直打半兽人，没有这个军队系统会断开打半兽人的游玩心流体验。
2. 剧情：除了“怪咖”的设计让我亮眼，其他的说实话我个人不太喜欢，但经典了（我看了剧透），而对它的剧情演绎没什么兴趣，也不太喜欢凯勒布里鹏。
3. 弱流派：像本次游戏的主要剧情体验当中，我以为我要么成为匕首大师或者弓箭大师。结果主要的战斗是靠剑去维持，弓箭清理杂兵，匕首这个系统纯粹是路边捡来的。在《刺客信条2》中，虽然反杀机制强，但还是会推荐通过刺杀来完成任务目标。打这个半兽人队长，不是远程免疫就是匿踪击杀免疫。不是很直观的感觉到这两武器系统的收益，最终我的流派是主远程和剑，吸取获得弓箭数量，然后清理杂兵好让剑去输出。
