游戏任务等级：50+的黑客流 通关本体主线

从夯到拉：顶级

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">整体初印象与总评</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">关键词：紧张刺激、狂战士、探索</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">总体评价：这是一款RPG要素战斗机制很不错的游戏，</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">加分项：技能树的构成，我没有玩完过《看门狗》，V的技能构成，黑客流派，场景交互，打击感和战斗体验非常好。它最牛的是它的关卡设计，作为演示关卡的漩涡帮食品工厂，你前面的不同的选择会影响后续的剧情展开，极大地丰富体验和剧情。中文配音也很好。</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">减分项：剧情。首先当你玩过《刺客信条2》、《消逝的光芒》实际上你会觉得杰克的死太必然而导致没什么感觉。未完成作品。整部作品透露出未完成感，且他们的价值观不太好，我认为强尼的塑造不如《斗破苍穹》的药老了，不符合朴素价值观。然后对于完成度极高的“漩涡帮食品工厂”设计并没有在整个剧情进行设计。而导致整款游戏又变成了线性体验，就好像你尝过一次好菜比如《孤岛惊魂3》里的烧大麻的关卡，它的背景音乐，关卡设计，剧情推进揉在一起是一道好菜。但后面就尝不到了，令人失望。</font>

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心玩法体验</font>
+ <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">这款游戏最核心的玩法有没有抓住你？它给你带来的核心爽点、最让你难受 / 无聊的点分别是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  我觉得它的战斗设计和技能设计是十分适配《赛博朋克2077》世界观的。它的载具机制比《看门狗》要好吧，提供了自动驾驶功能。且一上手是FPS在过渡到成熟的流派，战斗体验很爽。  
</font><font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  核心爽点：</font>

1. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">当我扮演使用黑客流技能直接冲进敌人面前，来一顿重启义眼，突触熔融，突触熔融就解决敌人的爽感，我的的确确在扮演传奇人物大名鼎鼎的V。</font>
2. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">“食品工厂”的关卡设计，你会发现有不同解法是一件很值得满足玩家探索欲望且感到新奇的点。比如我可以在与小田遇难的情况下通过二段跳救回小田挺好的。</font>
3. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">义体人太多了，而且左上角弹出人物进行远程对话挺满足世界体验的</font>
4. <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">支线任务。虽然支线任务大部分会是重复的。但我不知道是完成的过快还是因为有不同的完成方式，导致我觉得还好。体验丰富，我是自发地想要了解强尼银手的过往，罗恩的过往。</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">  难受点：</font>

1. 肯定是剧情，它的剧情体验不够成熟，不够好。作为一部3A巨作，在经历多次跳票且用“食品工厂”关卡宣传，它的剧情脚本太拉跨了对比《GTA5》或者《消逝的光芒》。就跟《消逝的光芒2》一样，说好的你的每一个选择会对后面剧情、环境产生影响。结果成了双向二极管，且势力都不是什么好人。
2. 人物塑造，好不容易打天下了，没几天活了，就不能为身边的人做做事情吗？维克托等，都已经成为了地下之王，还得亲自去月球执行任务，人物弧光和成长我是一点都没有见到，结局的表现让我感觉回到《艾尔登法环》我都成艾尔登之王了，接着去幽影地挨揍了。
3. 破坏成就感的支线任务和经济系统。我都成大名鼎鼎一个委托才4000$，请人现在这么便宜了？不知道义体多少钱吗？

# <font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">长线游玩体验</font>
<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">随着游玩时长增加，你对这款游戏的兴趣是上升、持平还是快速下降？你觉得影响你持续玩下去 / 想要弃坑的核心原因是什么？</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">上升，但实际上到后期只有下降了，因为剧情的吸引力就很快消失了。</font>

<font style="color:rgb(31, 35, 41);background-color:rgba(0, 0, 0, 0);">核心原因：剧情。一款RPG游戏实际上终究还是剧情占比更大。反例《艾尔登法环》这样的魂类游戏，当你先体验了《只狼》再去体验《艾尔登法环》你发现明明能讲好故事的，但是制作者偏不，靠玩家猜。我个人是不喜这样的状况出现的，所以我不会玩到幽影地。又比如百灵鸟的剧情设计，一开场实际上就是带着利用来的，主角看不明白，又是救他的唯一稻草了，我就不想继续DLC剧情展开了。</font>
