# 介绍
  “我要玩A! pex！”。
   如果压力大，你可以尝试玩《Apex》
  “不要让战斗停下来！”
  
# 整体初印象与总评
  用 3 个以内的关键词概括这款游戏给你的整体感受，你对它的总体评价是正面、中性还是负面？核心的加分 / 减分项是什么？
  
  关键词：FPS，电子竞技，战斗爽！
  
  总体评价：纯粹的大逃杀快速战斗。

加分项：
1. 打击感。战斗爽，我蛮喜欢“兹崩”的，现在没了：（。它的打击反馈，枪械多样，还有近战。打击感实在是太棒了。近战就像是蓄意轰拳。
2. 快节奏。落地捡枪就是打，死了直接下一把。对于枪械基本上捡起来就能用，对配件的需求不是很多，对子弹的需求可太多了。主要直接下一把的设计，直接省略了返回大厅的时间实在是太强了。
3. 丰富的游戏内容。我还没有体验完所有英雄的技能已经不同枪械的特点。但我基本上就用RE45打近点，长弓或复仇女神打远的就完事了。

减分项：
1. 对局环境。太吃固排了，在新手时期了解游戏的过程中，总会遇到秒退的，直接少打多，而作为新手我不知道我也退就行了。在个人枪法没有问题，大局战况没错误的情况下，总会有队友送的太狠，而且这游戏在被告知“没三个人根本玩不了”的情况下，我能救队友救队友。在3h的对局后我才知道圈太疼了，最后几个范围的圈得先进圈。但是队友太抽象了非得和别人打，我作为掩护最后连圈都进不了而没招，这种一个人什么都做不了的负反馈太狠了。相较于传统FPS的对抗，我又不能选择让自己轻松的打法。太吃操作了。
2. 一个人的游戏决策较少。基本战斗窜到大脑，前压代替思考。就算是队伍里面三个人都有远程狙的情况下，动力哥依旧前压到圈外和敌人3人整队对抗，还语音言“能不能狙倒一个”。哇塞，我能做什么？我只能拿狙在敌人高移动下抽奖，它倒地得视情况立马上前帮助，结果由于队友没看见我标记的藏在掩体后的敌人，优势情况瞬间逆风。而后毒圈来了无力回天。我能做什么游戏决策呢？
# 核心玩法体验
（最爽的地方 / 最难受的地方）

核心玩法：大逃杀对枪

最爽的地方：
- 倒一个、倒两个，我1打2尽力了，嘿嘿嘿。
- 在枪战中拿到一个令牌，拿到两个令牌。决赛圈还有复活点，复活吧！我的队友！
最难受的地方：
- 没招了。
