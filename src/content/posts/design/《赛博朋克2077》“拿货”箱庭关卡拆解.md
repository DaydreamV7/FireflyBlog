# 前言
  在2013年1月11日首个宣传片

  在2018年宣传片[https://www.bilibili.com/video/BV1AW411w7Gc](https://www.bilibili.com/video/BV1AW411w7Gc)引起热议 2020年4月16日发售。

  这个玩法演示是我们为什么拆解这个关卡的核心：[https://www.bilibili.com/video/BV1is411F7PR](https://www.bilibili.com/video/BV1is411F7PR)

  你能在实际的游玩中感受到阉割游戏内容（参考：[https://www.bilibili.com/video/BV1Ft4y1C7ko](https://www.bilibili.com/video/BV1Ft4y1C7ko)）

### 感受
  [https://www.bilibili.com/video/BV1is411F7PR](https://www.bilibili.com/video/BV1is411F7PR)

  肯定不可能从游戏的实机演示去拆解关卡，核心是对漩涡帮食品工厂那段关卡进行拆解。

  但是我想写下关于实机演示的感受。

+ 阉割了对于一个关卡不同进行的决策。这是一个巨大的工程量，在整个游戏进程中，只有漩涡帮食品工厂这段实机演示部分做得是最成功，最能体现制作者们的野心和强大的体验。但是会带来巨大的工作量即使是一开始作为序章部分的从左侧破窗来解决机关枪敌人都没有这样的提示了，我的游玩很单一解，只在食品工厂体会到了决策分支。
+ 维克托的义体部分。将商店和场景交互在一起，不知道为什么这个做好的部分不提供，在实际游戏中换成了UI界面选择这种代入感不强的交互。我没体验过扫描器的放大视野。
+ 对话系统完全以玩法为主导的。
+ 讲解了技能会对场景做出不同的互动
+ 三类远程武器的演示，还有几种敌人腿部会有敌人语音即不同的击杀反馈。
+ 黑入人体被删了。
+ 没感觉要打罗伊斯啊，正常游戏流程没打
+ 最后介绍了每一个选择都能产生相应的后果对世界和剧情造成影响，当时《消逝的光芒2》也跟着这样宣传。

这个实机演示也是我为什么做这个关卡拆解案的重要原因之一。即使在发售版本被阉割了一部分内容，也依旧是模板的关卡设计。

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">一、关卡核心定位与顶层设计目标（拆解开篇定调・必答）</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本关卡在主线流程中处于什么位置？（序章后首个大型核心主线 / 前期玩法验收关 / 剧情关键转折点），它承接了哪些前置剧情，又为后续哪些核心主线埋下了关键伏笔？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">前期玩法验收关，是整部游戏的关卡设计体现。</font>

2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">从策划视角，本关卡的</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">3 个核心设计目标</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">是什么？（比如：全玩法新手教学 / 夜之城帮派世界观塑造 / 多路径玩法验证 / V 与杰克的角色羁绊深化 / 主线剧情核心转折）</font>
+ 展现多路径玩法验证
+ 多路径下的夜之城世界观塑造
+ 各种势力的盘根错节
+ 鼓励玩家尝试不同分支进行不同体验
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本关卡对玩家的核心能力考验是什么？它要求玩家掌握哪些前期核心玩法，又给了玩家哪些容错空间？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">选择自己认为的最佳游戏策略，需要玩家掌握关卡中的路径和剧情的实现是具有不同分支的。</font>

并没有给玩家容错空间，以理解来看算回档。

4. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本关卡的玩家核心目标（主目标 + 可选隐藏目标）分别是什么？目标设计如何与剧情、玩法形成强绑定？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">主目标：推进游戏剧情带走“小平头”。</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">隐藏目标：解决布里克。</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">剧情上：玩家解救了布里克能够在后续的剧情中得到相应的帮助，获得“小平头”才能推进游戏主线剧情。</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">玩法上：与分支剧情强绑定，丰富了玩家的决策。玩家的决策能够影响后续的剧情，比如可以选择军用科技也能选择不解救布里克。</font>

## 分支设计思路
这才是我想要拆解的部分。

总共三个阶段

准备阶段-对话阶段-支线阶段。

+ 准备阶段：提供给喜欢支线重剧情的玩家
+ 对话阶段：重剧情和战斗玩家不同的决策
+ 支线阶段：剧情和探索类玩家的正向反馈和收获。

实际上核心就是在强沉浸强分支的开放世界理念中，加入了分支影响后续剧情这种长远决策带来的新奇或者沉浸感体验。

1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">若按剧情节点与玩法节奏，可将本关卡完整流程拆分为哪几个核心阶段？（例：开场驱车前往工厂→与漩涡帮谈判→工厂内行动→拿到 Relic 芯片→逃亡撤离→收尾剧情）</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">策划设计该关卡的多路径的核心目的是什么？</font>
+ 丰富玩家决策。多路径会让玩家主动了解最优策略，按照自己想要获取的游戏资源（不同剧情、武器获取）来重新决定路径。
+ 提高代入感，彰显分支影响后续剧情。通过玩家进行更多的选择来影响后续剧情达到沉浸式体验。
+ 延长游戏时间。一般玩家了解多分支情况，大概率会读档来进行不同策略
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">不同路径在</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">流程动线、玩法侧重、剧情演出、敌人配置</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">上，有哪些核心差异？不同路径分别给玩家带来了什么样的体验？</font>
+ 干掉罗伊斯路径能够没有BOSS战，简化战斗流程。
+ 不敢掉罗伊斯路径会出现BOSS战，敌人配置上相对较多且有BOSS演出，剧情代入深刻
+ 交易成功，体现了分支后续剧情开发世界玩法，剧情演出，给玩家带来了最佳决策的优异感
4. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">与对话分支设计中，不同对话选择会触发哪些不同的流程结果？（比如和平拿到芯片 / 直接触发战斗 / 触发隐藏剧情），策划通过对话选择实现了哪些设计目的？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">详情看思维导图。</font>

+ 丰富游戏的决策
+ 增强游戏体验和代入感即强沉浸强交互
+ 不同决策的差异化体现
+ 彰显不同剧情对后续剧情影响的设计理念
5. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">多路径设计中，策划如何保证「无论玩家选哪条路，都能完成核心剧情目标，不割裂主线叙事」？又如何给不同玩法偏好的玩家（潜行党 / 射击党 / 剧情党）提供对应的正反馈？</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">引导玩家拿到“小平头”</font>

不同反馈这里并没有给不同玩家反馈，主要是剧情党能进行不同分支。

6. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">关卡的可选隐藏内容（比如工厂内的情报收集、隐藏道具、支线伏笔）有哪些？它们如何丰富关卡的流程深度，又如何服务于世界观塑造？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">解决布里克。查出内奸。</font>

+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">丰富游戏人物</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">横向拓展游戏广度</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">深化了赛博朋克世界观且体现了漩涡帮的毒辣和势力的盘根错节。</font>

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">五、敌人配置与战斗空间设计（玩法核心拆解・选答）</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本关卡的敌人分为哪些类型？（例：漩涡帮普通杂兵 / 重装改造敌人 / 杜姆杜姆精英 BOSS），不同类型敌人的 AI 行为逻辑、攻击模式、弱点分别是什么？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">杂兵主要分为三种：</font>

+ 干扰性。比如黑客、摄像头来干扰玩家的决策
+ 突击性。直接和玩家进行火力对抗
+ 隐蔽型。需要玩家主动才能打死这个藏在掩体后的敌人。
+ 罗伊斯BOSS。会有范围性攻击，高数值攻击，弱点会有黄色高亮标记。
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">敌人的刷新位置、配置密度，如何匹配关卡的流程节奏？（例：谈判区域低敌人密度，工厂内部战斗区域高密度，撤离阶段动态刷新）</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">刷新和配置的密度相对分散，会引诱着玩家走上必经之路。</font>

3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">战斗区域的空间设计，如何服务于战斗玩法？（例：掩体分布、高低差设计、迂回路线、可互动爆炸物 / 场景杀）</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">掩体会再玩家的路径附件，而停车场则需要玩家对偏四周型的掩体进行更复杂的战斗决策。</font>

4. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">关卡的战斗难度曲线是如何设计的？从谈判破裂的初期战斗，到工厂深处的推进，再到撤离阶段的追逐战，难度如何逐步递增？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">逐步递增，实际上是根据选项来的，当玩家没有杀死罗伊斯，会出BOSS战而导致难度上升。</font>

5. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">精英战设计，有哪些核心机制？它如何检验玩家在本关卡学到的战斗技巧？策划设计这场战斗的核心目的是什么？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">掩体，击杀落点。实际上该游戏的战斗体验并不是很复杂，它的战斗策略不是强丰富。</font>

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">六、叙事节奏与角色塑造设计</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本关卡通过哪些剧情演出、对话细节、行为设计，塑造了杰克、杜姆杜姆这些核心角色的性格？这些角色塑造如何影响玩家的剧情代入感？</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">一开始的对话比如杰克不愿意坐下：体现了杰克信不过漩涡帮</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">杜牧杜牧话痨</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">罗伊斯的脾气火爆</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">其实基本都比较潜移默化并没有给我强烈的剧情既视感，但依旧有沉浸式体验。</font>

2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">关卡的剧情节点与玩法流程是如何无缝结合的？（例：驱车路上的对话铺垫世界观，谈判环节的对话选择直接影响玩法流程，撤离路上的对话深化角色羁绊）</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">在进入工厂时候，杰克会不断铺垫世界观，</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">在谈判环节的对话选项能够影响后续的发展，</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">撤离路上杰克和V不同的观点说明了两人理念上的不同</font>

3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本关卡的整体情绪节奏是如何设计的？按流程分段，每个阶段的情绪强度（1-5 分）分别是多少？如何通过「剧情铺垫→谈判紧张→战斗爆发→逃亡高潮→收尾放松」的张弛交替，把控玩家的情绪曲线？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">4分。</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">当进入到工厂里的那一刻，无论是环境氛围还是对话都体现了进入一个实打实的黑帮漩涡帮。当战斗爆发玩家需要杀出重围的刺激连贯。最后结局对话的收尾放松。情绪曲线是比较简单的低高低。</font>

4. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本关卡的</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">峰值体验</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">和</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">终值体验</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">分别设计在哪个环节？策划如何通过玩法、剧情、演出的结合，强化玩家的记忆点？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">峰值体验一个是在对话分支那里，另一个是停车场那里。</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">玩家通过罗伊斯的强势剧情演出来强化玩家的记忆点</font>

5. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">关卡通过哪些细节，铺垫了「Relic 芯片」「荒坂赖宣」「赛博精神病」这些后续核心主线的关键信息？如何实现「单关卡完整叙事」与「全游戏主线伏笔」的平衡？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">漩涡帮的人都是多义体表现，他们需要镇定剂来维持自己的大脑，所以会出现罗伊斯的暴躁而不能谈生意，铺垫倒是没有，更多的是世界观的体现。</font>

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">八、设计复盘与专业总结</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">从策划视角，本关卡最成功的设计点是什么？它们分别实现了什么样的设计效果？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">剧情分支的把握，</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">准备阶段-进行阶段-其他阶段</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">通过不同阶段体验不同的分支来满足更多玩家的倾向并丰富游戏的策略二不单一。</font>

2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本关卡的设计存在哪些不足？如果你来优化，会提出哪些可落地的调整方案？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">由于是序章阶段，整体更偏向与走流程，并不是一个丰富的游戏关卡，倒是很好的演示了他们的分支剧情。</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">我会调整布里克解救的吸引，因为对于弱探索的玩家，他大概率错过这一设计亮点，只是想着通过主线剧情。用一些场景的互动和暗示来吸引玩家发现和在后续中寻找这种分支决策。</font>

3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本关卡的哪些设计逻辑，可以复用在其他开放世界 RPG 的线性主线关卡中？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">《消逝的光芒》实际上很多重剧情类偏开放世界游戏都可以尝试去实现分支剧情影响后续发展。</font>

4. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">一句话总结：本关卡对于《赛博朋克 2077》这款游戏，最核心的价值是什么？</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">展示了游戏卖点之一的分支剧情影响后续剧情，并铺垫了游戏世界观，增强沉浸感。</font>
