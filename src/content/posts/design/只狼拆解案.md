# 游戏类型与描述
《只狼》是一款ARPG类型的游戏，你讲扮演一个日本刺客，追随自己的主公，一路破解永生的谜题，完成自己的刺客之道

<font style="color:rgba(0, 0, 0, 0.85);">“《只狼》是 FromSoftware 开发的</font>**<font style="color:rgb(0, 0, 0) !important;">硬核动作冒险类游戏</font>**<font style="color:rgba(0, 0, 0, 0.85);">，以日本战国时代为背景，融合 “忍者生存” 与 “魂系挑战” 核心特质。游戏核心定位是 “以架势博弈为核心的高难度动作体验”，通过 “攻防交替的拼刀机制”“立体机动的忍者玩法” 与 “东方美学的场景叙事”，为硬核动作玩家提供 “突破极限的挑战快感” 与 “深度沉浸的战国冒险”。目标用户聚焦于能接受高死亡惩罚、享受操作打磨过程的核心玩家，核心诉求是通过精准操作战胜强敌，解锁碎片化剧情，感受 “凡人之躯比肩神明” 的成就感。——豆包”</font>

# 设计分析
## 战斗机制
可以看到《只狼》的战斗机制丰富多样。可以抽象为一个ACT游戏，比如玩家一碰就碎《闪避刺客》、《武士：零》。《只狼》的战斗机制也能完成主体的游戏流程

就算没有架势条、忍杀和危。也是一款机制独特的ACT游戏。你可以用移动，攻击，格挡，闪避这几个基础的战斗机制内容来完成主体游戏大部分的战斗体验。

### 招架（完美格挡）
那么如何做好加法便是这个游戏的体验了。

招架，知乎文章（[招架机制本质](https://zhuanlan.zhihu.com/p/96736247)）写得挺好的较为全面，但实际上可以抽象

1. 抵挡敌人的进攻
2. 没有玩家HP削减
3. 敌人产生后摇——削减敌人HP

就算剥离架势条的存在，招架机制的独特就是这样明显。本文无法面面俱到，根据实际游戏，确实敌人是处于一直格挡状态，以弦一郎为例子，基本攻击三下便会触发完美格挡进行反击，而玩家触发招架将弦一郎的攻击完美格挡，就可以进行反击（必然削减敌人HP）。所以本文不会研究太细，需到用时再另修。而细致的文章有[《弹开机制》](https://www.bilibili.com/opus/476020326460216298)

通过<font style="background-color:#FBDE28;">闪光</font>效果来增强完美格挡的效果，完美格挡的时机需要看敌人起手式之类的时机，且不同的敌人不同的攻击需要完美格挡的时机不同。这需要玩家学习和背敌人的连招，这也是魂类游戏的独特的战斗。

通过敌人一直处于格挡状态并且只用基础的战斗机制内容，在音效，特效上的效果，招架这一机制的加入显著地提高的游戏动作的打击感和战斗快感，也造成了类似回合制的你来我往的战斗体验。

### 架势条
那么如果仅仅加入招架这一机制，可以想象游戏的流程是多么烦长，而架势条的加入显得更加独特。这段描写的时候并没有对平衡性考量，而是一直以游戏一次结局的数值体验而对比，基础印象是，敌人血条较长，攻击频繁，伤害高，玩家伤害低，血条较短。

所以如果在这种基础上，玩家叮叮当当至少要打很多回合且犯错较低才能过Boss。这样重复度较高且容错小的流程体验必然不会让轻度玩家接触这款游戏。

而架势条的设计是独特且吸引的，很少有游戏会卖防御上面的机制特点。

架势条，当在格挡状态受到攻击或直接受伤害会增加架势条，但没有进行战斗的时候或战斗中的间隔较长能够恢复架势条，血量越少架势条恢复的间隔需求更长且更容易增长架势条。当架势条满，玩家会失衡，有较长前摇失去操控易被敌人攻击。敌人会失衡，身上会出现红点可以进行忍杀。

游戏的核心决定胜负的资源是 HP，但是出现了新的几乎是决定胜负的资源架势条。废话就是玩家会有更多的战斗决策和思量，但是由于只增加了这一个独特的胜负资源所以也无法将战斗决策增大到很多，当玩家熟悉也是确定性游戏，所以讨论它对战斗体验的增加。

大部分的应用场景就是玩家攻击敌人，敌人格挡小幅度增加架势条。而玩家格挡敌人的连续攻击，玩家增加较多的架势条。这也就说明ACT游戏一般要放大另一种机制或者增加新的机制来造成独特的战斗体验，它就像是从格挡是放大出来的，鼓励玩家进行招架，来增加这场战斗的有利性。类比游戏《武士：零》玩家结束敌人生命就是靠自己的武士刀砍中敌人，也有高风险高回报的砍中敌人发射的子弹来决定胜负。架势条的增加无疑是增加了玩家的战斗体验，虽然感觉上从平衡性思考由于敌人的连续攻击导致玩家的架势条容易大幅度涨，但是玩家攻击敌人，就算敌人一直处于是格挡状态，但由于架势条的增加导致产生了正收益，主观上玩家的攻击是有效的、正反馈的，鼓励了玩家的攻击，增强了玩家的战斗体验。

### 危
Boss的危攻击是加快战斗流程和增强战斗体验

+ 突刺危
+ 横扫危
+ 擒拿危
+ 雷击危

每次危被玩家化解就能够造成敌人的后摇，能够削减递减敌人HP或者较大地增长敌人的架势条，

没有化解将造成大量的HP损失，并且增加较大的架势条

相应的从平衡性分析，玩家遭受危基本需要一个葫芦才能恢复失去的HP。

单次战斗体验流程从类回合招架反击战斗体验过渡到随机施展危的Boss导致玩家需要多种决策反击的战斗体验，并且对于玩家一次攻击增加的架势条或者削减敌人的HP数值来看，危的收益是较高的，丰富的玩家的战斗决策也加快了战斗流程，使架势条满进行忍杀这一决定胜负资源更能体现。

### 忍杀
当处于玩家在敌人背后进行攻击或敌人架势条满失衡

这个主要特点就是核心战斗体验的结算，它是类比多种游戏的处决，是一切结束的标志。

近期能够对这个机制进行类比的视频是[《释放阿凡达》](https://www.bilibili.com/video/BV1Bb41z5Eac)

如果玩家紧张刺激的战斗是起承转合，那么忍杀属于合，是对战斗剧本高潮的衔接和结局的表现。所以特别的动画表现让动作与画面有张力，更让战斗体验增强使整个战斗体验完整。

而背后忍杀是发挥了忍者这一设定和体验，并且也是鼓励玩家通过蹲伏降低敌人对自己的可见度。

## 体验目标
作为一个玩家我轻而易举代入的核心体验是

**我要扮演一个忍者为了主公调查不死真相，当主公下落不明寻回主公，肃清路途上的敌人**

+ **紧张**，敌人的伤害太高了，即使是路上的一个小怪，只用3、4下攻击就能清空HP而导致死亡。而且一般一个战斗区域附近的敌人比较紧密，需要玩家策略如何处理。
+ **偷感**，我可以攀在悬崖边偷袭敌人，也可以潜伏起来偷袭敌人，像一个忍者一样。
+ **刺激**，不像《骑马与砍杀》也不像《艾尔登法环》，快节奏的攻击体验，危和招架几种组合起来，打击感十分强烈，战斗十分投入，容易进入心流。
+ **帅**，忍杀的画面演绎，使动作张力和人物表现更加突出



## 设计目的
### 重生 龙胤之力
玩到后期实际上可以不需要这个机制。

这属于一种补偿，游戏的保护机制，保护玩家的游戏体验，削弱游戏的负反馈，也是构造游戏世界观的一环。

对于新手玩家来说这是不可或缺的，但我觉得这是一种很独特的削弱游戏负反馈的手段。因为决定胜负的关键不是一条命的HP值了，因为玩家还有一条命。自然玩家不会很心疼自己的HP值，而勇于对魂类游戏世界进行探索并利用道具葫芦来恢复自己的HP。

### 葫芦
和重生比较绑定在一块，是游戏的保护机制，实力较强的玩家也不需要这个。葫芦就相当于《超级马里奥》的蘑菇，多一条命令玩家有恃无恐，且独特的恢复7/10左右的HP，属于另一条命，以较长的前摇来维持游戏平衡。

### 勾绳
纵向游戏空间的利用，高机动战斗的延伸。

### 绝技
玩家收集欲望的补充，丰富战斗机制，增加战斗决策如一字斩带来的游戏收益。

### 架势条
丰富游戏的战斗并加快了游戏的战斗节奏，因为玩家攻击是有收益的，会更倾向于攻击。推测设计目的是为了实现“回合制”感的即时战斗体验。

+ 单独分离出来作为决定游戏胜负的第二因素
+ 给玩家提供即使敌人挡住玩家攻击，玩家的攻击依然有收益的正反馈
+ 认为是从格挡上延伸的，是游戏机制探索的新思路

# 游戏感受
## 菜鸟游玩
初次游玩的时候，我像个菜鸟一样充满多余的动作，十分搞笑也对游戏内容充满新奇。

跳进悬崖外3次，蹦蹦跶跶很容易死。偷感极重地蹲在敌人背后，并且跳过游戏提示。在初次的精英怪那里死了8次。我用的是轻薄本笔记本电脑和学习版进行游玩，所以会有卡帧的情况。

这说明了游戏的上手难度并不高且游戏体验生动。

我想独特的忍杀动画是能够快速代入，进入心流体验的重要途径。

由于我是急切通关的玩家查阅了攻略，因为我不知道为什么能进入平田宅邸。

## 面对精英怪
当我打不过守在寺庙前的孤忍众，在悬崖下通过卡bug修脚来解决敌人，逃课和昏招这样不同的游戏战斗策略是比较搞笑轻松的游戏体验

<font style="color:rgb(32, 33, 34);background-color:rgba(255, 255, 255, 0.84);">蚺蛇重藏，纵使我偷他背身，依旧会被他庞大的身躯撞飞，只好用油火打法干掉他</font>

## 战Boss
<font style="color:rgb(32, 33, 34);background-color:rgba(255, 255, 255, 0.84);">鬼形部我实在是打不过，只能回到回忆里的平田宅邸去刷技能点。</font>

然后就和蝴蝶夫人打了四个小时，是惊心动魄又奇招频出，耍赖和逃跑共出，道具和贪刀齐飞。这是我印象深刻的Boss战。

第一个小时，根本打不过，就算打过了一阶段，二阶段的纸人造成真伤防不住，太阴了。

第二、三个小时，通过闪避-攻击，造成读指令，麻木的执行操作几乎无伤过第一阶段，也要被二阶段幻术干掉，甚至鸣种数量少还不能补充，又是幻术小怪，又是连段攻击老婆婆。扛不住。被嘲讽小狗不知道多少次了。

第四个小时，终于通过秦王绕柱和读指令干掉她了。

我是第一次在一个事物上坚持那么久，抱着干掉她的决心进行游戏，还查阅资料只为了更好地过关。实实在在地沉浸到游戏里面，并收获过关而带来的游戏进展。但是我当时心态是麻木和解脱，前两个小时那快节奏的叮叮当当是刺激和爽的打击体验。

后续游戏体验就是打弦一郎，我也收获了“别人会骗你，但弦一郎不会的”独特战斗体验。



当我对招架这个机制重新认识并运用之后，基本上我每次战斗用我的既定套路去打敌人。压制敌人AI-触发敌人完美格挡-我进行完美格挡-攻击-破解危-压制敌人AI，如此反复，中间穿插用忍义手鞭炮来造成敌人后摇，自己可以喝药或者贪刀来缓和战斗节奏。固定套路让游戏的战斗决策趋于可解了，但我的的确确成长了，相较于新手。

# 改良建议
1. 佛雕师Boss设计极其不合理。就像是《夏洛特烦恼》一群成年人演高中生，如果出现一个年轻高中生那么会带来很大的不协调感。亦然在快节奏攻击下出现佛雕师这种不能按传统套路进行攻打的Boss，太恶心了，所以我会跳过他去打别的Boss或者逃课让他跌入悬崖。所以可以更改他的Boss机制设计，像义父那样显得有独特战斗节奏即可。
2. 碎片化叙事。这是宫崎英高游戏的特点，他似乎认定他无法讲好一个故事，导致遐想空间太小，魂学家用物品介绍，地图设计等去结构游戏世界背景和剧情，咋这么费劲啊。玩家与游戏世界的连接脆弱了，虽然剧情演绎很棒，但仅此而已。所以添加更多的文本和剧情还有NPC互动是玩家对游戏世界连接的需求。
3. 战斗决策固定套路。快速消耗纸人，游戏对不死斩的削弱是不鼓励玩家用不死斩的。而像我那种鞭炮流固定套路，对于一个成长的高手玩家所需要应对的随机性较少。随机性可以再丰富一下，这里是主观上的臆测，因为我也不能提出更好的建议
4. 绝技对战斗影响较少。像空中忍杀，绝技，想要在战斗中用好比较困难且收益较少，绝技没有那种像忍义手增加战斗决策的补充的感觉，而是炫技那种增加不同的攻击动作。像[《释放阿凡达》](https://www.bilibili.com/video/BV1Bb41z5Eac)那样，但是对玩家反馈并不明显，所以可以改进它对部分敌人有特殊收益。

# 补充
按照道理来讲应该要有数值分析还有敌人AI分析对平衡性分析进行补充，但是一款游戏的平衡性分析要的时间也久，暂不补充。

本文目前只是片面的对游戏主要的战斗部分进行拆解，至于升级，成长等辅助游戏体验没有进行分析。
